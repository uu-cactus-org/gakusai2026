# 画面

| 経路              | 内容                                                 |
| ----------------- | ---------------------------------------------------- |
| `/`               | 入口。各ゲームのランキングと、サイネージ表示へ進む   |
| `/water-shooting` | WaterShooting のランキング。PC とスマホ向け          |
| `/signage`        | 会場のモニター向け。全画面で、ランキングを自動で送る |

| `/uu-jump` | UU-JUMP のランキング。マップごとに、速い順 |
| `/admin` | 管理画面。記録の整理、PC の表示名の変更、配布する zip のアップロード |
| `/games` | 部員向けの、ゲームの zip の配布([games.md](games.md)) |

ランキングとサイネージは、10 秒ごとにランキングを取り直します。新しい記録は、再読み込みをしなくても出ます。

## `/water-shooting`

並べ替え、絞り込み、ページは URL に持ちます。URL を渡せば、同じ表示を開けます。

| 引数         | 既定    | 内容                                                          |
| ------------ | ------- | ------------------------------------------------------------- |
| `sort`       | `score` | 並べ替え。`score`、`playSeconds`、`reachedStage`、`createdAt` |
| `difficulty` | なし    | その難易度だけに絞る                                          |
| `player`     | なし    | そのキャラだけに絞る                                          |
| `result`     | なし    | `cleared` か `game_over` だけに絞る                           |
| `page`       | 1       | ページ(1 始まり)。1 ページは 20 件                            |

- 読めない値は、既定に戻します。
- 各行の順位は、並べ替えを変えてもスコアでの順位のままです(API の `rank`)。
- 幅が狭い画面では、表の代わりに 1 件を 2 行にまとめた一覧を出します。

## 統計(`/water-shooting`、`/uu-jump`)

ナビの中央の「統計」を押すと、ランキングの代わりに、時間ごとのプレイ数のグラフを出します。もう 1 度押すか、ブラウザの「戻る」で、ランキングへ戻ります。
時刻は日本時間です。テストの記録は数えません。30 秒ごとに取り直します。

| 引数    | 既定   | 内容                                                                                  |
| ------- | ------ | ------------------------------------------------------------------------------------- |
| `view`  | なし   | `stats` で統計を出す                                                                  |
| `range` | `day`  | 期間。`3h`(直近 3 時間、10 分ごと)、`day`(1 日、30 分ごと)、`all`(全期間、1 時間ごと) |
| `day`   | 今日   | `day` で見る日。`2026-11-21` か `2026-11-22`。学祭の外の日は、近いほうの日            |
| `trim`  | `true` | 最初と最後の、記録が無い時間を横軸から省く                                            |

`all` は、4 日を超えると 1 日ごとにまとめます。

## `/signage`

ゲームごとには分けていません。1 つの URL を開いたままにすれば、登録してあるボードを順に映します。
1 つのボードを数ページ送ったら次のボードへ進み、最後まで行ったら先頭へ戻ります。

モニターごとに、URL で設定を変えられます。

| 引数       | 既定 | 内容                                          |
| ---------- | ---- | --------------------------------------------- |
| `interval` | 10   | 1 ページを映す秒数(3〜300)                    |
| `rows`     | 10   | 画面に一度に並べる件数(3〜20)                 |
| `pages`    | 3    | 1 つのボードで送るページ数の上限              |
| `wide`     | なし | `true` で、画面の中央に 16:9 の枠を取って描く |

既定では、10 件ずつ 3 ページで、30 位までを映します(UU-JUMP は、マップごとに 20 位まで)。

UU-JUMP は、1 ページに `rows` の 2 倍の件数を持たせ、ページの途中で下へ送ります。映す時間の最初の 6 割は一番上で止め、次の 2 割で一番下まで送り、残りの 2 割は一番下で止めます(`interval=5` なら、0〜3 秒は上、3〜4 秒で送り、4〜5 秒は下)。件数が `rows` 以下のページは送りません。WaterShooting は送りません。

WaterShooting は、`interval` にかかわらず、1 ページを 4 秒で送ります(`boards.ts` の `interval`)。`interval` が効くのは UU-JUMP です。例: `/signage?interval=15&rows=8&pages=2`

### iPad から 16:9 のモニターへ出す

M チップの無い iPad は、外部モニターへミラーリングしかできません。iPad の画面は 4:3 に近いので、そのままでは左右に黒い帯が出ます。
`/signage?wide=true` で開いて全画面にし、モニターの側を「ズーム」(上下を切って横幅いっぱいに広げる表示)にすると、16:9 の枠が画面いっぱいになります。
枠は画面の中央に取るので、Safari のバーが出たままだと上下にずれます。必ず全画面にします。

操作:

| 操作                | 内容                   |
| ------------------- | ---------------------- |
| 「全画面にする」/ F | 全画面の切り替え       |
| ← →                 | 前のページ、次のページ |
| 画面の左 1/4 を押す | 前のページ             |
| 画面の右 1/4 を押す | 次のページ             |
| スペース            | 自動送りの一時停止     |

- 全画面への切り替えは、ブラウザの決まりで、人の操作(ボタンかキー)が要ります。開いただけでは全画面になりません。ブラウザをキオスクモードで起動する場合は、操作は要りません。
- 全画面のあいだは、ボタンとマウスカーソルを隠します。キーと、画面の左右を押す操作は効きます。
- 映している間は、画面が消灯しないようブラウザに頼みます(対応しているブラウザのみ)。
- 文字の大きさは、画面の大きさと `rows` に合わせて変わります。縦は行が、横はボードの列が収まるところまで大きくします。列を足したら、`boards.ts` の `widthEm` も増やします。

### ボードを足す

`src/features/signage/boards.ts` の一覧に 1 件足します。ボードは、渡されたページを表示し、今あるページ数を
`onPageCount` で知らせるコンポーネントです。手本は `src/features/water-shooting/signage-board.tsx` です。

## `/uu-jump`

UU-JUMP(ジャンプアクション)のランキングの画面です。API の仕様は [uu-jump.md](uu-jump.md) にあります。

- 並べ替え(タイムが短い順、ジャンプが少ない順、新しい順)ができます。順位は、どの並べ替えでもタイム順のままです。
- ランキングはマップごとです。並んだボタンでマップを切り替えます。`?map=マップ1` で直接開けます。省くと、名前の順で先頭のマップです。
- ゴールまでが短い順に、1 ページ 20 件です。10 秒ごとに取り直します。
- 記録が 1 件も無いあいだは「まだ記録がありません」と出ます。
- 背景は、ゲームのタイトル画面の校舎の絵です。題字は絵から切り落とし、文字で出しています。
- サイネージでは、マップを名前の順に、1 マップ 1 ページ(`rows` の 2 倍の件数、既定で 20 位まで)で映します。`pages` は効きません。

## `/admin`

本番では、Cloudflare Access の GitHub ログインを通った人だけが開けます([access-setup.md](access-setup.md))。
左上に「(GitHub のユーザー名) としてログイン中」と出ます。ユーザー名が取れないときはプロフィールの名前、それも取れないときは「ログイン中」だけになります。ローカル(`vp dev`)ではログインの確認を飛ばします。

上の段で、管理する対象を切り替えます。

| 区分         | 内容                                                                    | 直接開く URL                                  |
| ------------ | ----------------------------------------------------------------------- | --------------------------------------------- |
| ランキング   | 記録の整理。ゲームごとのタブがある                                      | `/admin`(WaterShooting)、`/admin?tab=uu-jump` |
| デバイス管理 | PC の表示名の変更                                                       | `/admin?tab=devices`                          |
| 配布ファイル | 部員に配る zip のアップロード、ダウンロード、削除([games.md](games.md)) | `/admin?tab=games`                            |

UU-JUMP のタブは、WaterShooting の記録と同じ操作ができます。絞り込みは、種類、PC、マップです。

### WaterShooting の記録

ランキングと違い、テストの記録も、どの PC からの記録かも見えます。15 秒ごとに取り直します。

| 操作         | 内容                                                                                     |
| ------------ | ---------------------------------------------------------------------------------------- |
| 外す         | テスト扱いにして、ランキングから外す。記録は残るので、「戻す」で元に戻せる               |
| 戻す         | テスト扱いをやめて、ランキングに戻す。エディターやデバッグ用のビルドからの記録にも使える |
| 消す(ゴミ箱) | 記録を消す。元に戻せないので、確認の画面を挟む                                           |

- 並べ替え(新しい順、スコアが高い順)と、絞り込み(種類、PC、結果)ができます。1 ページは 50 件です。
- 迷ったら「外す」を使います。消すのは、誤送信など残す意味がない記録だけにします。

### PC

表示名を書き換えて「保存」を押す(または Enter)と、ランキングと中継の管理画面に出る名前が変わります。
表示名は 1〜32 文字です。各 PC の記録の数と、ID も見えます。

## まだ無いもの

- 見た目の作り込み。今は、ゲームの背景・キャラの絵・書体・配色を当てただけです。色は `src/styles.css` の変数、素材は `src/assets/` にあります。

## 見た目の分け方

トップ(`/`)と管理画面(`/admin`)は、どのゲームのものでもないので、共通の見た目(shadcn/ui の neutral)です。
ゲームの見た目は、そのゲームの画面と、サイネージでそのゲームを映しているあいだだけ当たります。

- 中身は `src/styles.css` の `.theme-water-shooting` です。`useDocumentTheme`(`src/lib/use-document-theme.ts`)が、画面を開いているあいだだけ `<html>` に付けます。
- ゲームを足すときは、`.theme-<ゲーム名>` を足し、そのゲームの画面で `useDocumentTheme` を呼びます。サイネージには、`src/features/signage/boards.ts` の `themeClass` と `Backdrop` で渡します。
- 自分の記録の強調。ゲームから「この記録」を指して開くには、記録が何ページ目かを引く API が要ります。
- 記録をまとめて消す操作。今は 1 件ずつです。

## 共有したときのカード(OGP)

URL を SNS やチャットに貼ったときのカードは、`index.html` の `<head>` に書いています。画像は `public/thumbnail.png`(1200×630)です。

- どの URL を貼っても、同じカードが出ます。画面ごとには変えていません。画面は 1 つの `index.html` をブラウザ側で描き分けているので、変えるには Worker で HTML を書き換える必要があります。
- URL は絶対で書いています。独自ドメインを当てたら、`index.html` の `gakusai2026.uucactus-share.workers.dev` を書き換えます。
