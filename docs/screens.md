# 画面

| 経路              | 内容                                                 |
| ----------------- | ---------------------------------------------------- |
| `/`               | 入口。各ゲームのランキングと、サイネージ表示へ進む   |
| `/water-shooting` | WaterShooting のランキング。PC とスマホ向け          |
| `/signage`        | 会場のモニター向け。全画面で、ランキングを自動で送る |

どの画面も、10 秒ごとにランキングを取り直します。新しい記録は、再読み込みをしなくても出ます。

## `/water-shooting`

並べ替え、絞り込み、ページは URL に持ちます。URL を渡せば、同じ表示を開けます。

| 引数         | 既定    | 内容                                                          |
| ------------ | ------- | ------------------------------------------------------------- |
| `sort`       | `score` | 並べ替え。`score`、`playSeconds`、`reachedStage`、`createdAt` |
| `difficulty` | なし    | その難易度だけに絞る                                          |
| `player`     | なし    | そのキャラだけに絞る                                          |
| `result`     | なし    | `cleared` か `game_over` だけに絞る                           |
| `page`       | 1       | ページ(1 始まり)。1 ページは 20 件                            |

- 読めない値は、既定に戻します。
- 各行の順位は、並べ替えを変えてもスコアでの順位のままです(API の `rank`)。
- 幅が狭い画面では、表の代わりに 1 件を 2 行にまとめた一覧を出します。

## `/signage`

ゲームごとには分けていません。1 つの URL を開いたままにすれば、登録してあるボードを順に映します。
1 つのボードを数ページ送ったら次のボードへ進み、最後まで行ったら先頭へ戻ります。

モニターごとに、URL で設定を変えられます。

| 引数       | 既定 | 内容                             |
| ---------- | ---- | -------------------------------- |
| `interval` | 10   | 1 ページを映す秒数(3〜300)       |
| `rows`     | 10   | 1 ページに並べる件数(3〜20)      |
| `pages`    | 3    | 1 つのボードで送るページ数の上限 |

既定では、10 件ずつ 3 ページで、30 位までを映します。例: `/signage?interval=15&rows=8&pages=2`

操作:

| 操作                | 内容                   |
| ------------------- | ---------------------- |
| 「全画面にする」/ F | 全画面の切り替え       |
| ← →                 | 前のページ、次のページ |
| スペース            | 自動送りの一時停止     |

- 全画面への切り替えは、ブラウザの決まりで、人の操作(ボタンかキー)が要ります。開いただけでは全画面になりません。ブラウザをキオスクモードで起動する場合は、操作は要りません。
- 全画面のあいだは、ボタンとマウスカーソルを隠します。キーでの操作は効きます。
- 映している間は、画面が消灯しないようブラウザに頼みます(対応しているブラウザのみ)。
- 文字の大きさは、画面の大きさと `rows` に合わせて変わります。

### ボードを足す

`src/features/signage/boards.ts` の一覧に 1 件足します。ボードは、渡されたページを表示し、今あるページ数を
`onPageCount` で知らせるコンポーネントです。手本は `src/features/water-shooting/signage-board.tsx` です。

## ローカルで確かめる

```bash
vp run db:migrate:local   # 初回だけ
vp run dev
vpx scripts/seed-local.ts # 確認用の記録を 45 件入れる(ローカルのみ)
```

## まだ無いもの

- 見た目のデザイン。今は shadcn/ui の既定の配色です。色は `src/styles.css` の変数で変えられます。
- 自分の記録の強調。ゲームから「この記録」を指して開くには、記録が何ページ目かを引く API が要ります。
- 管理用の画面(記録の削除、表示名の変更)。
